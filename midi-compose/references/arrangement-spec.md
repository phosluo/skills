# 配器表

写音符**之前**要填完的一张表。它一物三用：脚本的输入、A/B 的变量、成品的验收基准。

## 为什么必须有

模型（也就是你）会拿"训练数据里最常见的那个"去补你没写的东西。**没写下来的字段越多，成品就越套路**——不是你 prompt 写得差，是留白太多。

而且散文没法验收。一段写在文档字符串里的段落描述，不能逐字段和成品对照；一张表可以。

**没填完不要开始写音符。**

## 九个字段

| 字段 | 要写什么 |
|---|---|
| 1. 用途与时长 | 交付场景、总时长、要卡的秒数或帧 |
| 2. 调性与音阶 | 主调、音阶、有没有转调 |
| 3. 速度 | BPM、一小节秒数、总小节数 |
| 4. 段落与能量 | 每段的小节区间 + 能量值 1–10 |
| 5. 和弦 | 每段的进行，和弦字母 + 罗马数字 |
| 6. 声部进出 | **每个声部在第几小节进、第几小节出** |
| 7. 主动机 | 长度、全曲出现几次、每次改哪个要素 |
| 8. 音色分工 | 每个声部的 GM program 和音区 |
| 9. 混音意图 | 频率分工、声像、混响 |

第 6 个字段最容易漏，但它是"编曲"和"把音符写出来"的分界线。第 4 个字段里的能量值是后面逐段验收的依据。

## 填好的实例

`examples/reggae.py` 的配器表：

| 字段 | 值 |
|---|---|
| 用途与时长 | 纯音乐示例；约 32 秒（10 小节 × 3.0 s + 尾音） |
| 调性 | A 小调（自然小调，无转调） |
| 速度 | 80 BPM；一小节 3.0 s；共 10 小节（bar 0–9） |
| 段落与能量 | 前奏 bar 0（能量 3）｜A 段 bar 1–4（5，其中 bar 4 降到 3 做 break）｜B 段 bar 5–8（7）｜结尾 bar 9（4） |
| 和弦 | 前奏 Am7｜A 段 Am7–D9–Am7–D9｜B 段 Fmaj7–G–Am7–Am7｜结尾 Am7。罗马数字：i7–IV9–i7–IV9｜VI maj7–VII–i7–i7 |
| 声部进出 | 鼓/吉他 bar 0 进｜贝斯 + 管风琴低音区 bar 1 进｜**贝斯 bar 4 撤出做 break**｜**bar 5 贝斯回归 + 管风琴 16 分 + 铜管旋律一起进**｜结尾全体转长音 |
| 主动机 | 2 小节（铜管 bar 5–6 的动机）；bar 7 换尾、bar 8 压缩重现；每次只改音区或尾音 |
| 音色分工 | 贝斯 ch0 prog33（E1–G2）｜skank ch1 prog27（A3–E5）｜管风琴 ch2 prog16（A2–E4，bubble 跨两个八度）｜小号 ch3 prog56 + 长号 ch4 prog57 低八度（E4–E5）｜鼓 ch9 |
| 混音意图 | 低频只留贝斯 + 底鼓；skank 走中高、pan 38；管风琴 pan 90 靠边；铜管 reverb 55 稍靠后 |

对照 `reggae.py` 的 `PROG`、`HORNS` 和 `bar in (1, 5)` 这些分支，可以看到表里的每个决定在代码里都有一处对应。**填不出这一栏，说明这段编曲其实还没想清楚。**

## 一个实测教训：对比要落在主导声部上

这个示例最初 B 段和 A 段的响度只差 **0.3 dB**——等于没有对比。修的时候走了弯路，值得记下来。

**第一版改法（错）**：在 B 段加东西——管风琴 16 分、铜管旋律。改完 A→B 只从 0.3 涨到 **0.7 dB**，几乎无效。

把每个声部单独渲染出来量，才看清原因：

| 声部 | A 段 | B 段 | 段落变化 |
|---|---|---|---|
| **贝斯** | **−24.4 dB** | −23.6 dB | +0.8 |
| 鼓 | −32.6 | −32.2 | +0.4 |
| skank | −37.5 | −37.9 | −0.4 |
| 管风琴 | −43.9 | −39.1 | +4.8 |
| 铜管 | −44.0 | −28.1 | **+15.9** |

铜管在 B 段其实抬了 16 dB，改动是生效的。**但贝斯比第二名（鼓）还响 8 dB、比管风琴响 19.5 dB，一个人占了整段约 80% 的能量，而它从头到尾一个音没变。** 在次要声部加的料全被淹没了。

**第二版改法（对）**：让主导声部也参与段落变化——bar 4 把贝斯撤掉做 break，bar 5 再进。同时把管风琴和铜管的音量提上来，让它们真的听得见。

结果：

| 指标 | 改前 | 改后 |
|---|---|---|
| A 段 → B 段 | 0.3 dB | **2.5 dB** |
| A 段 → bar 5（跨过 break） | 1.2 dB | **4.2 dB** |
| LRA（全曲响度动态） | 2.0 LU | **5.1 LU** |

**结论：段落对比要动最响的那个声部。** 如果主导声部全程不变，在次要声部上做加减是白费力气。写完配器表先去量一遍每个声部的实际电平，再决定动谁。

**注意"响度"不等于"能量"。** 上面说的都是电平。能量还包括声部数量、音区高低、节奏活跃度——B 段即使电平只高 2.5 dB，声部数从 31 涨到 55，听感上的抬起也是成立的。电平只是最容易量化的那一项。

## 机器味自查

填完表逐条问一遍。**中的条目要么改掉，要么在表里写明为什么故意保留。**

### 结构

1. 段落长度全是 8 的倍数（4/8/16）——至少破一次
2. 能量曲线单调上升——必须有一次回落（间奏、桥段、撤声部）
3. 总时长刚好整分钟，尤其卡在 3:30
4. 相邻两段之间没有任何一项不同

### 编曲

5. 编制从头到尾不变——至少要有一次"进"和一次"出"
6. 全曲只有一个 loop 从头用到尾
7. 加花永远落在小节 4 的倍数上
8. 没有非人声的 hook——一段能被人记住的器乐旋律
9. 所有声部同进同出（一起开始、一起停）

### 演奏

10. 全部严格对齐网格，一点偏移都没有
11. 力度没有层次，所有音挤在同一个 vel 附近
12. 长音没有任何起伏（持续音乐器没上 `cc(…, 11, …)` 或 `bend`）

### 混音

13. 所有声部挤在同一个音区
14. 低频堆叠（贝斯、底鼓、钢琴左手抢同一段）
