# 随机种子启发设计

用外部随机性提供新的联想起点，再用设计判断把它收敛成适合任务的作品。种子是灵感来源，不是产品内容，也不是质量或唯一性的保证。

## 1. 确定任务边界

从用户请求和已有材料确认交付物、受众、目的、内容及品牌或技术约束。没有明确交付物时先询问；可合理推断的风格偏好自行决定。通用方法不等于默认制作生产力应用落地页，始终完成用户实际要求的作品。

已有品牌规范、可访问性和内容准确性优先于种子联想。用户只要求创意方向时，交付方向即可；要求制作时，继续完成实际产物。

## 2. 生成外部随机种子

通过 shell 执行本 skill 内的脚本（相对路径以 skill 所在目录为基准）：

```bash
bash scripts/generate-seed.sh
```

脚本使用 OpenSSL 生成 256 位随机字母数字字符串。读取工具输出作为本次创作的灵感，不要自行编造一串“看起来随机”的字符。若依赖不可用，可使用其他系统随机源通过 shell 生成等价字符串；无法执行时说明限制，不要声称已生成。

同一方向的修改沿用本次种子和设计方向；用户要求全新方向或多个独立方案时，为每个方向生成新种子。不要为了迎合预设风格反复抽取种子。

## 3. 从模式提炼方向

观察整串字符及局部关系：重复与中断、疏密节奏、大小写变化、数字组合、近似对称、可联想到的形态或声音。超越首几个字符的表面联想，但不必解释每一个字符，也不要套用固定的字符到风格查表。

挑选少量有表现力的线索，组合成一个连贯的设计方向，并将其落实为适合当前媒介的具体决定：

- 色彩：主色、背景、强调色及其使用比例。
- 构图：阅读顺序、网格或非对称关系、留白与信息密度。
- 字体：气质、字重对比、字号层级与排版节奏。
- 视觉语言：图像、形状、材质、线条，必要时包括动效。

这些联系是创意联想，不是字符串客观蕴含的意义。数字可以启发布局比例或节奏，无需机械转为尺寸、颜色值或模块数量。

在动手前用几句自然语言说明所选方向及关键视觉决定，不展示种子。除非用户要求比较方案，否则自行选择一个方向并继续制作。

## 4. 实现并检查

让方向影响实际构图、层级和视觉语言，而不只是替换默认模板的配色。用专业判断舍弃削弱可读性、可用性或整体协调的联想；不必让所有设计维度都随机变化。

根据用户要求完成可用的交付物。条件允许时查看实际渲染，检查视觉方向是否成立、信息层级是否清楚、文字是否易读，以及该媒介相关的显示和交互问题。修正发现的问题；无法查看渲染时如实说明验证范围。

不要将原始种子作为标题、文案、装饰、图片文字、替代文本或隐藏标记写入交付物。最终回复提供作品入口和简短方向说明即可，无需附上随机串或完整联想过程。
